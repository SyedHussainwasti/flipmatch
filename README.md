# 🃏 Memory Match

A memory card game — flip two cards at a time and match all 8 emoji pairs.

## How to play

Tap cards to flip them. Match all 8 pairs in as few moves and as little time as you can. The timer starts on your first flip.

## Controls

- **Tap / click** cards to flip them
- **Restart** button shuffles a fresh board

Open `index.html` in any modern browser. No build step, no dependencies.

## Files

- `index.html` — the page: all the buttons, cards and text you see
- `styles.css` — the look: colors, sizes and layout
- `app.js` — the brain: the game rules and what happens when you tap
